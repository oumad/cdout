the loop

Four moves, every time

No file dialogs, no copy-pasting paths. The context comes from wherever you already are.

Select

Highlight files or a folder in Explorer or Finder. cdout reads the selection over COM on Windows, AppleScript on macOS.

Prompt

Hit Ctrl+Alt+A (Cmd+Alt+A on macOS), describe the outcome in a sentence.

Approve

Read the exact command it proposes. Edit it, reject with feedback, or run it.

Run

Output feeds back to the model. It verifies the result, then stops — or takes the next step.

under the hood

Built like a tool you'd trust with a shell

Explorer & Finder aware

The agent sees your current folder and selection — through the Windows COM bridge, or AppleScript on macOS. “Rename these” just works — no paths to type.

One tool: your shell

Every action is a single, editable proposal — run_powershell on Windows, run_shell (zsh) on macOS. Approve, edit inline, or reject with a note the model reads back. Read-only probes run on their own; anything that writes waits for you.

Sessions

Every prompt becomes a saved session in a sidebar, ordered by recency. Resume, rename, or delete — history lives on disk as plain JSON.

Loop detection

A watchdog spots repeat, ping-pong, and no-progress patterns and escalates — pausing auto-run and forcing the model to stop and reassess.

Skills

Drop a Markdown file to teach it a CLI — ffmpeg, imagemagick, exiftool ship built in. User skills get scanned and quarantined if unsafe.

Provider routing

Model prefix picks the path: ollama: local, anthropic: direct with prompt caching, everything else through OpenRouter.

Nothing runs
until you say so

cdout is an assistant, not an autopilot. The model can propose a command, but the shell only fires on your click. You can read it, edit it, send feedback, or walk away — every proposal is answered explicitly, so the conversation never gets ahead of you.

Execute — run it, feed the output back
Execute all — auto-run the following steps too
Reject with feedback — tell it what to fix
Dismiss / Stop — kill the run, the process too

bring your own model

Local, direct, or 400 models on one key

Route by the model you pick. Private on your machine, cached through Anthropic, or anything OpenRouter offers.

private

Ollama

Local models on localhost:11434. Prompts never leave the box — fully offline, fully free.

cached

Anthropic direct

Straight to api.anthropic.com with your key for prompt caching — the 5–10× cost cut OpenRouter's wire drops.

default

OpenRouter

One key, ~400 models — Claude, GPT, Gemini, Llama. cdout pins data_collection: deny on every request.

get it

Download cdout

Every tagged release ships Windows and macOS builds. Pick one.

latest release · Windows x64
cdout_x64-setup.exeNSIS installer — the usual double-click install recommended cdout_x64_en-US.msiMSI package — for managed / group-policy installs cdout-portable-x64.zipUnzip anywhere, run cdout.exe — no install
latest release · macOS universal
cdout_universal.dmgIntel + Apple silicon — drag to Applications recommended

Windows: press Ctrl+Alt+A anywhere to open the spotlight. Everything lives in %APPDATA%\cdout.
macOS: the build is unsigned, so the first launch needs a right-click → Open. Press Cmd+Alt+A for the spotlight, and allow the Finder permission prompt — that is how cdout reads your selection. Everything lives in ~/Library/Application Support/cdout.
Either way: add a model key under Settings → Providers, or point it at a running Ollama.
